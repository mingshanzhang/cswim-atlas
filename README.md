# CSWIM Research Atlas

Explore CSWIM 2022–2026 by year, topic, method, theory and research stage. Linked charts, paper details, collaboration networks and CSV exports use the same filtered records.

Website: https://mingshanzhang.github.io/cswim-atlas/

English is the default language. Use the English / 中文 controls to switch languages while keeping the current filters.

The index contains 640 proceedings-directory entries. Reading depth is recorded per entry: abstract coding, reviewed excerpts, reviewed papers or pending coding. Conference-wide program reconciliation and expert validation remain open. Author names are merged across papers only with verified identity evidence.

Original proceedings are linked from paper details; this repository contains metadata and short reading summaries, not proceedings PDFs.

To preview locally, serve this folder with a local HTTP server and open its displayed address. No front-end installation or build is required.
